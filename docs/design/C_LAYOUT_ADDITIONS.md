# C 布局本地补充

2026-10-21。用户确认按复核建议补充，采用直接复用既有 C HTML 的方式；本轮未再次调用 Stitch 生成模型，未向云端上传新增稿。

## 新增四页

- 31 图片右键菜单 · C：快速查看、在访达中显示、拷贝文件路径、收藏、图片信息。按需出现在照片旁，保留紧凑窗口标题条。暂不加入壁纸、批量导出与删除。
- 32 基础多选 · C：3 张选中图，1 个当前项；底栏显示选中数量与总数。⌘ 单击/Shift 范围选择为设计约定；没有加入常驻批量工具条或虚构总大小。
- 33 胶片条展开 · C：12 张真实示例照片；选中项、文件名、序号及前后按钮整合到胶片条。移除重复的中部导航组；侧栏/返回/更多仍在左下，缩放仍在右下。主图保持原适应尺寸。
- 34 图片信息 · 浅色 · C：沿用同一个 Inspector 布局与主题 tokens，只切换 HTML 主题类；与现有深色 16 形成对照。没有全局替换 CSS 选择器。

深色网格 12 已与 11 共用 C 的几何和 token 规则，本轮复核后保留。没有采用新 09 的双层窗口壳。鹰眼继续后置。

## 顶栏与工具分工

网格顶部仅保留原生风格窗口控件、当前文件夹。大图顶部没有应用工具栏。搜索/排序/信息/显示设置留在网格底部；主题、密度、帮助在显示菜单。图片操作通过右键菜单；不加入画板、相册、头像、全局废纸篓导航。
