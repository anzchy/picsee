# picsee 分阶段开发计划

更新：2026-10-21 · 版本：v0.2 · 状态：原生实现待执行；设计基线已更新。

技术路线：**Swift + SwiftUI + AppKit**。先阅读 [架构设计](./PICSEE_ARCHITECTURE.md)；功能依据为 Picview 功能清单 `docs/PICVIEW_FEATURES.md` 与技术分析 `docs/PICVIEW_ANALYSIS.md`（本地研究资料，不在公开仓库）。本计划不表示任何原生阶段已实现或验收通过。当前仓库有浏览器原型和20份设计状态稿，尚无 picsee Swift 源文件或 Xcode 工程。

设计依据按顺序为：用户确认的 **C · Quiet Image Canvas**、[主设计规范](../design/DESIGN.md)、[20页本地 mockup 索引](../design/prototypes/picsee-browser/states/index.html)与[本地补充说明](design/C_LAYOUT_ADDITIONS.md)。Stitch 云端未采纳的07/08等探索稿不作为实现基线。原生代码不打包 HTML/CSS 或 Stitch/REA/npm 运行时。

## 1. 交付顺序与范围

```text
P0 技术验证、设计映射与命令底座
 → P1 单图打开、C 沉浸画布与加载
 → P2 文件夹连续浏览、授权与可选 Filmstrip
 → P3 C 网格、多选/菜单/基础信息、缓存与性能收敛    ← 日常使用 MVP
 → P4 桌面窗口、置顶、交互与幻灯片
 → P5 元数据、标签、基础编辑与导出
 → P6 兼容、可访问性与发布         ← 首发 v1
 → P7 OCR、RAW/HDR/Finder 等增强   ← 按实测与需求逐项加入
```

每阶段以**可演示行为 + 验证记录**为完成条件，上一阶段的关键门槛未通过，不靠新增功能掩盖问题。首发不以“与 Picview 所有设置逐项一致”为目标。

### 1.0 Picview 功能到阶段的对应

表中阶段代表计划，不表示已经实现；格式项以 P6 公布的受测能力为准。

| 参考功能 | 实现阶段 | 首发边界 |
|---|---|---|

| 连续翻图、子目录、扩展名过滤、排序 | P2 | Finder 跟随排序留 P7；元数据排序允许渐进补全 |
| 可选 Filmstrip、网格、目录侧栏 | P2/P3 | Filmstrip 整合翻图与序号；默认收起 |
| 多文件夹图库与“所有照片”汇总 | P3-15 | 只保存已授权文件夹的引用，不导入、不复制图片 |
| 基础多选、图片右键菜单、收藏 | P3 | 不含批量导出/删除；保持单一当前项与选择集合分离 |
| 缩略导航图/鹰眼 | P4-06 按需评估 | 不常驻，不阻塞 MVP |

| C 自动隐藏界面/工具常驻、浅深外观 | P1/P3 | 核心浏览体验，前移至 MVP；不同于高级窗口模式 |

| 图片/文本桌面 pin、阴影/透明度、剪贴板打开 | P4 | 跨重启持久 pins 留 P7 |
| 基础命令路由与快捷键 | P0/P1/P3 | 原生菜单、按钮和键盘调用同一命令 |
| 鼠标/触控板预设、可配置快捷键、幻灯片 | P4 | 应用内生效；全局快捷键留 P7 |
| 基础 Inspector：名称、尺寸、类型、日期、大小 | P3 | 浅深主题共用结构；异步读取，未知值不伪造 |
| 高级 EXIF/IPTC/GPS 信息、Finder 标签 | P5 | 基础 Inspector 的扩展，不重复实现面板 |
| 裁剪、旋转、翻转、另存、质量与 metadata | P5 | 静态图片；原文件覆盖延期 |
| 在访达中显示、拷贝路径、图片信息入口 | P3 | 31页基础右键菜单，不新增顶部工具横栏 |
| 复制图片、分享、打印、其他应用与 Trash | P5 | 不自动降级为永久删除；不自动升级为批量流程 |
| GIF 动画、PDF 分页、系统可读 RAW | P6 | 未通过可延期，但必须从首发支持声明中去除 |
| SVG/AI/PSD/Sketch/WebP 等扩展格式 | P6 能力核对 / P7 扩展 | 区分完整解码、静态首帧与 Quick Look 预览 |
| OCR、复制文字、系统翻译入口、主体提取 | P7 | 系统提供相应文本操作时接入；不承诺自建翻译服务 |
| HDR、增强 RAW 与更多缩放渲染能力 | P7 | 独立素材、硬件和资源验收 |
| Pro、订阅、购买恢复 | 暂缓 | 付费模式未决定；不进入浏览核心依赖 |

### 1.4 最小状态模型与实施前冻结点

以下默认行为已在 2026-10-21 grilling 中由用户确认冻结（仍不是已实现的事实）。P0-09/P3-09开始时记录为命令/状态表；如变更须同步 DESIGN.md、用例及验收，不由每张 mockup 自行决定。

- `BrowserSelection` 持有 `selectedItemIDs`、`currentItemID`、`anchorItemID`；图片身份不使用索引代替。切换过滤/目录/排序时与对应快照版本协调。
- **Space 预览范围（用户已确认，2026-10-21 grilling）**：只选1项时按当前过滤/排序后的目录序列翻图；多于1项时按同一排序后的选中集合翻图。Viewer保存来源快照版本和有序ID集合；Esc恢复原选择集合、当前项和滚动锚点。遇删除/权限变化按已冻结序列核对移除，不悄悄扩大到全部目录。
- ⌘切换单项、Shift以锚点做范围选择；方向键/修饰键和焦点联动在原生 NSCollectionView 中验证并固化，不能仅凭静态蓝框判定完成。
- `ViewerChromeState` 显式描述隐藏、可见、用户常驻及交互锁定；菜单/Inspector/Filmstrip/键盘焦点形成保持可见条件。用可控时钟验证约2.5秒，不靠散落定时器或字符串替换。
- `DisplayPreferences` 保存外观、侧栏/宽度、Filmstrip、文件名、缩略图适应方式/尺寸、工具常驻。搜索词是瞬时过滤，不跨启动恢复，不与布局偏好混存。
- 原生基础命令从P0建立：Space、箭头、Esc、Enter、0/1、+/−、⌘F；⌘O 对应可选文件/目录的“打开…”，⌘I 显示/隐藏基础 Inspector。阶段尚未实现时不展示已可用的快捷键提示。
- 图片右键动作采用不可变目标身份/快照，避免菜单打开后当前项改变导致作用到别图。多选菜单仅开放已实现且语义明确的集合操作；基础多选不自动授权批量导出/删除。

| `P7-01` OCR/Live Text | 选取复制图片文字 | P4 坐标与输入模式成熟；检查系统/硬件可用性、异步任务失效 | 缩放/旋转/翻图后文字覆盖层不漂移、不回流旧结果 |

| `P7-03` LibRaw 增强 | 增加系统无法解码的相机文件 | 具体相机样本、库许可/打包、内存和阻塞风险 | 每个声明相机/格式有测试，嵌入预览与完整显影分开 |
| `P7-04` HDR | 高动态范围显示 | 目标显示器、位深/色彩/缓存/导出全链路设计 | SDR/HDR 切换与缓存隔离、不同屏幕验证 |
| `P7-05` Finder 跟随排序 | 符合用户已有列表顺序 | 独立 `.DS_Store` 解析，权限和损坏输入处理 | 明确何时跟随、何时回退；不影响普通排序 |
| `P7-06` 自适应/瀑布流 | 改善混合长宽比图片浏览 | P3 网格与滚动位置稳定 | 重排不跳选中项，布局变化不触发全目录重解码 |
| `P7-07` 格式扩展 | SVG/WebP/AI/PSD 等具体需求 | 真实样本与预览/完整渲染边界 | 不执行文件附带脚本；能力声明与实测一致 |
| `P7-08` 超大图切片 | 地图/长图等专业需求 | 实测证明现有分辨率限制不能满足；额外内存/渲染架构 | 切片预算、缩放细化、取消和色彩一致 |
| `P7-09` 持久 pins / 全局快捷键（自动更新已前移到 P6-08，ADR-006） | 使用便利与版本维护 | 各自有存储、冲突或签名验证要求 | 每项独立验证，不以一个开关替代完整流程 |

Rust、Windows/iOS、账号、云同步、语义搜图、批量资产管理/批量导出删除工作流、插件系统、复杂调色暂不在计划内；**P3基础多选、集合浏览与 P3-15 多文件夹汇总不等同于批量资产管理或导入式图库**。若产品方向转向这些需求，重新定义目标和依赖，不从现有文件夹浏览器自然膨胀而来。

## 10. 测试素材与性能目标

### 10.1 固定可复现条件

所有性能结果写明：机型/芯片/内存、macOS、Release 构建与 SHA、显示器/scale、存储介质、素材 manifest、缓存状态、重复次数。P0 选择一台 16 GiB Apple Silicon Mac 作为建议基准；若实际只有其他机器，先记录实际配置并重新校准，不伪称该基准已测试。

| 集合 | 建议内容 | 核心验证 |
|---|---|---|
| S1 | 50 张 1–12MP JPEG/PNG/HEIC，含透明与 EXIF 方向 | 正确显示、颜色/方向、菜单操作 |
| S2 | 5000 张混合图、嵌套目录、同名不同路径 | 首批可用、全局排序、滚动与取消 |
| S3 | 48MP、100MP 合法大图与合成超限头 | 峰值、限额、降采样与恢复 |
| S4 | GIF、多页 PDF、RAW 及其他格式真实样本 | 帧/页语义、预览与完整支持区别 |
| S5 | 损坏/截断文件、同路径替换、目录 symlink、无权限、卷卸载 | 错误恢复、标识与权限边界 |
| S6 | 3 个查看器 + 3 个 pins，重复与不同大图 | 共享任务、全局预算与关闭释放 |

“冷应用缓存”只代表清空 picsee 内存/磁盘缓存；不能当作 OS 文件页缓存也已清空。热磁盘缓存仍需读取/解码，热内存缓存才是像素命中，报告分别给出。

### 10.2 初始工程目标，P0 校准后作为门槛

| 指标 | 初始目标与测量边界 |
|---|---|
| 命令反馈 | 导航/缩放输入到状态反馈 p95 ≤ 100 ms；不等于像素已完成解码 |
| 普通图首个可用预览 | S1、本地 SSD、冷应用缓存 p95 ≤ 500 ms；RAW/PDF/S3 单独报告 |
| 热内存翻图 | 有相应尺寸像素命中的场景，输入到呈现 p95 ≤ 100 ms |
| 目录首批 | S2 本地 SSD 首批可浏览内容 ≤ 1 s；扫描最终完成单独记录 |
| 目录一致性 | 停止写入后普通小批变更 2 s 内核对完成；重扫/慢卷显示进度并另测 |
| 图形交互 | 60 Hz 基准下记录 frame/hitch；连续缩放与滚动不得出现可复现的长时间主线程解码阻塞 |
| 资源有界 | 全局 worker/队列/缓存不超过配置；反复浏览同一素材三轮后不持续线性增长；返回空闲状态记录 retained objects 与 RSS，不要求系统立即归还全部 RSS |
| 磁盘缓存 | 写入/淘汰收敛后不高于配置高水位；异常断电/坏索引后可重建，不影响原文件 |

时延指标每类至少 30 次采样，记录 p50/p95 与极值；小样本不足不写“通过 p95”。性能未达标时记录 bottleneck、取舍和新的验证，不能直接放宽目标后删除原结果。

### 10.3 必须保留的行为回归

- A→B→C 乱序返回、复用 cell 串图、多窗口单方取消。
- 排队前/排队中/执行中取消，continuation 与资源租约均恰好收尾。
- 文件同路径替换、外部修改、扫描中新增删除、事件丢失重扫。
- 清空缓存期间旧写入返回、淘汰期间读取、坏载荷、磁盘满。
- Retina 像素换算、方向和裁剪变换、跨窗口焦点、输入框吞快捷键。
- C工具显隐/常驻/交互锁定，隐藏时命中与可访问性，Tab唤回；避免13/14静态导出误改选择器的同类回归。
- Filmstrip展开/收起只保留一套导航；选择项滚入视口，左右组不碰撞，主图不因展开而额外缩小。
- 单选/多选/范围选择、当前项/锚点、搜索过滤/排序后选择核对、Space进入与Esc恢复。
- 右键目标固定，菜单展开后目录改变/文件消失/权限失效；快捷键不会同时触发菜单动作和翻图。
- 系统浅深切换、Inspector异步结果、偏好恢复、长文件名与800×680窗口。
- 未授权/过期 bookmark、卷卸载、应用重启、签名分发包恢复授权。
