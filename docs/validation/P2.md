### 运行 `probe-228-r2`（#228 合入后的 main 5e5b934，签名 Debug，沙盒开启，Mac mini @1x）

**方法**

- 以 `-PicseeAccessProbe` 启动签名 Debug 版。
- 9 个测试文件夹都经系统打开面板逐个选择：没有预先授权，也没有改动容器。
- 之后每一步都改变磁盘或文件夹状态，然后再次启动探查。探查每次写出每个 bookmark 的原始事实（plain 与 enriched 各一条），然后自行退出。
- 测试盘是 hdiutil 挂载的 .dmg，代替外接盘：USB 直接拔出与网络盘未验证。
- 选择用合成键盘输入（已披露）。

**结果（plain 与 enriched 一致）**

| 情况 | 分类 | 依据 |
|---|---|---|
| 卷已挂载 | readable | 列目录成功 |
| 卷已推出 | **diskNotConnected** | 卷 UUID 不在已挂载列表里。bookmark 仍解析到旧路径（stale），而且列出空挂载点也"成功"，所以只有卷 UUID 比对能判断 |
| 重新挂载 | readable | 同一 UUID |
| 同名的另一卷仍挂载 | **diskNotConnected** | 按 UUID 比对，没有被同名卷骗过 |
| 无 UUID 的卷 | 未产生 | MS-DOS 映像也有 UUID；这一情况未验证，按通用文案处理 |
| 同卷文件夹改名 | readable | 跟随 bookmark（26M-C） |
| 卷改名 | readable | 同一 UUID |
| 文件夹已删除 | **notFound** | 解析失败，NSCocoaErrorDomain 259 |
| 跨卷移动 | **notFound** | 与删除的错误完全相同，无法区分，所以文案只说「找不到」 |
| 移入废纸篓 | unknown，isInTrash=true | bookmark 仍能解析到废纸篓里；只有废纸篓检查能识别 |
| chmod 000 | **accessExpired** | 列目录被拒，NSCocoaErrorDomain 257，底层 NSPOSIXErrorDomain 13（EACCES）。这是 **POSIX 拒绝**，不是沙盒或 TCC 撤权 |
| 损坏的 bookmark | 未在真机做 | 改容器不被允许；只有单元测试覆盖 |

**延迟**：各步都在毫秒级。例如卷已推出时，读卷属性约 0.05 ms，扫描已挂载卷约 1 ms，解析约 3.4 ms。解析从未挂载卷，也没有弹出界面。

**结论**

- 外接磁盘未连接、找不到、授权失效三种原因能可靠区分，可以各用自己的文案。
- 废纸篓按标志处理为「找不到」，并且绝不自动打开（#231）。
- 无 UUID 的卷与无法分类的情况用通用文案「无法访问此文件夹」。
- 授权失效的证据仅限 POSIX 拒绝；真正的沙盒/TCC 撤权未验证。

**限制**

- 第一次运行（probe-228）无效。面板辅助脚本的合成 ⌘V 没有进入「前往文件夹」输入框，9 次选择都落在面板记住的旧文件夹。经所有者批准，该次运行的两个探查文件已改名保留，然后重跑。这次重跑经无障碍接口写入路径并读回核对，基线 18 条记录确认是 9 个不同的文件夹。
- 证据（JSONL、截图、步骤日志）保存在仓库外。
