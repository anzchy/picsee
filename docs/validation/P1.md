| OPEN-03 | Finder“打开方式 → picsee”与双击 | App 的 rank 是 `Alternate`；设为“始终以此方式打开”会改变系统状态，需要用户步骤 |
| OPEN-04 | 从 Finder 拖入窗口 | 跨 App 拖动尚未证明可由 computer use 稳定驱动；可先尝试，失败则保留未验证 |
| OPEN-01 | 冷启动且从未打开文件夹 | 需要空 Recent/grant store；设备规则禁止删除 sandbox container，需用户批准重置或 App 内清除入口 |
| VIEW-09 | A→B→C 且 A 最后完成 | 需要 DEBUG 延迟钩子；没有钩子时只能保留单元证据 |
| CHROME-01 | 隐藏工具不可被 VoiceOver 读取 | 截图不能捕获 VoiceOver 输出；可改用 Accessibility Inspector 的 AX tree 并明确证据类型，否则保留未验证 |

| PREF-02 | 切换系统“减少动态效果” | 需要修改辅助功能系统设置；属于用户步骤 |
