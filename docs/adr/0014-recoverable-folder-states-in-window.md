# ADR-014：可恢复的文件夹状态在窗口内显示，不用模态提示框

关联：P2-08，FOLDER-08、FOLDER-09、ACCESS-03、ACCESS-04；状态稿 22、26；原型 `states/prototype-states-22-26.html`（22-BD、26-BC；分支 `prototype/states-22-26`）；P2-08b #137、P2-08c #141；[ADR-013](0013-build-by-user-journey-slices.md)；[ADR-0008](0008-folder-access-read-only-app-scoped-bookmarks.md)、[ADR-0010](0010-folder-opens-in-the-grid-after-a-complete-scan.md)、[ADR-0011](0011-session-file-grant-bookmark-recovery.md)。

## 决定

文件夹打开后发现的**可恢复状态**（空文件夹、无法访问）显示在**网格外壳的内容区内**，侧栏和底栏保持可用。不再使用 NSAlert sheet。

### 22 空文件夹（22-BD）

替换现在的「此文件夹没有图片」提示框，以及点「好」之后的空白失败画布。

- **这一层有子文件夹：** 列出子文件夹（只显示名字，扫描前不显示数量），提供「包含子文件夹浏览」（复用 P2-04 的递归开关）和「选择其他文件夹…」。
- **没有子文件夹：** 列出最近打开的文件夹（`RecentFolder.openedAt`，最多 10 项）和「选择其他文件夹…」。
- **两种情况：** 内容区都是拖放目标，拖入其他文件夹即打开。

### 26 目录权限失效（26-BC）

替换 `ReconnectPrompt` 的提示框流程。

- **侧栏：** 失效的文件夹变灰并带 ⚠，子文件夹收起。「个人收藏」「最近查看」照常可用；其中来自该文件夹的图片打开时，进入同一个重连状态。
- **内容区按原因给出路：**
  - **授权失效：** 「重新选择文件夹…」，恢复后回到先前位置。
  - **外接磁盘未连接：** 不需要操作，卷挂载后自动恢复（FOLDER-09）；同时提供「选择其他文件夹…」。
  - **被移动或改名：** 原型给出「在新位置选择…」，但 ACCESS-03 现行验收是「目录被移动或改名时，最近项直接在新位置浏览」（P2 记录已注明直接浏览改名结果与验收不符、待 owner 决定）。这一支线待用户决定：保留现行验收（直接在新位置浏览、不出现本状态），或单独提交改写 ACCESS-03 验收并引用用户原话。
- **实现前须确认：** 三种原因能否可靠区分（卷挂载状态、bookmark 解析结果）。不能可靠区分时，退回"授权失效"的通用文案，不猜原因。
- **不变的规则：** 不从缓存绕过已撤销的权限（ADR-0008，计划 §1.3 第 26 行）。重新授权走系统打开面板，不改 entitlement。

## 考虑过的方案

| 方案 | 说明 | 取舍 |
|---|---|---|
| 22-0 / 26-0 保持模态提示框（现状） | 26 的提示框已在 @1x 真机验证（ACCESS-03） | 关掉提示框后窗口里没有说明，也没有再次入口；与状态稿 22、26 不符 |
| 22-A / 26-A 原稿：页内居中提示 | 与状态稿一致 | 没有利用已有的数据（子文件夹、最近打开、失效原因） |
| 22-C 列出非图片文件统计 | 解释"为什么是空的" | 现有扫描不统计非图片文件，需新增数据，否则就是伪造 |
| 26-D 三步引导重连 | 解释沙盒授权 | 文案重；系统面板不保证停在上次位置 |
| **22-BD、26-BC（选定）** | 用已有数据给出下一步：子文件夹或最近打开；按原因区分；侧栏局部标记 | 26 改变了一个已真机验证的流程，需重新验收；原因区分需先确认可行 |

## 后果

- **验收：** P2-08 写明采用 22-BD、26-BC。FOLDER-08、ACCESS-03/04、FOLDER-09 的「怎么确认」如需改动，按 AGENTS.md 单独提交，并引用上面的原话。
- **26 的真机证据：** ACCESS-03 现有的 @1x 真机记录针对提示框流程。改为页内状态后要重新做真机记录，旧记录不能直接沿用。
- **状态稿：** 22、26 两页以原型 22-BD、26-BC 为准，旅程页已挂"候选"卡片。正式状态稿按 UI 对照契约更新。
- **键盘与辅助功能：** 新状态须满足 DESIGN.md §6：可 Tab 聚焦，焦点可见，Esc 行为不变，VoiceOver 能读出原因与按钮。
