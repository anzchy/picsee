# picsee C：经典看图布局与极简设计评审

日期：2026-10-20。Windows 与 macOS 分别由两个子代理调研，主代理结合当前 C 的 JSX/CSS、浅色网格和隐藏控件后的深色大图截图复核。本轮仅评审，不修改原型。

## 结论

继续采用 C。大图已经实现完整画布和按需操作，下一步主要简化网格的信息密度，同时补齐隐藏控件后的可发现性、窗口操作和缩放语义。保留文件夹侧栏、底部入口、Space / 左右键 / Esc；不恢复顶部 banner，不引入其他布局方案。

极简的判断标准：图片始终是视觉主体，用户仍能明确知道当前目录、选中图片、返回方式和缩放状态。

## 当前 C 的修改建议

### P0：先减少网格噪声

1. **默认删除图片下第二行诗意描述。** 当前 `photo-caption` 的“灯火初上”等是演示标题，本地文件并无稳定来源。保留单行文件名，可选“只看图片”隐藏文件名。按现有 CSS，删除描述及相关空隙约可收回每行 24px，实际效果以调整后截图为准。
2. **单选状态只保留一种主要信号。** 目前整块蓝底、蓝色文件名和圆形勾选同时存在，容易让网格更像多选相册。建议用细蓝边框加弱文件名底色表达当前项；圆形勾选留给明确的多选操作。键盘焦点继续保持可辨认。
3. **移除侧栏底部原型说明。** “本地图片，随手浏览”“示例照片…”和“交互原型”放到项目说明；添加文件夹入口保留。图库分组可折叠，目录树作为主要内容。侧栏宽度可拖动，记住展开状态，不强制所有用户默认隐藏。

### P1：简化常驻工具，但保留上下文

4. **网格标题条只保留窗口控件和目录名。** 当前右上浅/深色双按钮和帮助入口属于低频设置，可收进外观/帮助菜单，外观默认跟随系统。保留现有紧凑标题条，不加第二排。长目录名截断并提供完整路径提示；侧栏收起后仍能辨认当前目录。
5. **底栏保留左下侧栏开关，收纳密度滑杆。** 左：侧栏＋当前文件/数量；右：搜索、排序、显示菜单。密度滑杆和网格显示偏好进入“显示”面板，图片信息入口也可保留或纳入该面板。Space 提示只在初次使用或无操作时出现。搜索激活时显示清除/恢复全部入口，不能仅靠一个轻微变蓝的图标提示筛选仍生效。
6. **大图保持三处分区，不增加永久横条。** 左下侧栏/返回网格/更多，中下翻页与序号，右下缩放。文件名按需显示；缩放控件里文字“适应窗口”和末尾 fit 图标目前指向同一动作，建议合并为一个清楚的模式入口。1:1 原始尺寸必须与适应窗口分开。

### P1：极简仍需完成的交互细节

7. **隐藏时机可配置。** 当前代码已有 1.6 秒延迟、底边/顶边唤回、Tab 恢复，以及菜单/缩略图/键盘操作时暂停隐藏；这些应保留。新增“始终显示工具”偏好，延迟可先试 2–3 秒再做实际用户验证。查看 EXIF 等面板时不要让相关入口难以找回。不照搬 FastStone 四边唤出：Mac 顶部菜单和底部 Dock 存在交互竞争。
8. **原生窗口操作与图片手势分清。** 网页灰色圆点只是装饰。原生版普通窗口必须提供真实红黄绿、可拖动窗口区域及菜单命令；放大图片后拖动用于平移，不能同时移动窗口。系统全屏的窗口控件跟随系统行为，不自行永久隐藏关闭入口。
9. **修正缩放百分比的含义。** 目前 `zoom` 是相对于适应窗口的 CSS 倍数，`zoom * 100` 并不等于源图像的真实像素缩放。原生方案需要明确适应窗口、1:1 与真实缩放百分比；不能把适应后的 125% 当作源图 125%。这属于后续功能设计要求，不能仅改文案即视为完成。

## 推荐下一版结构

| 场景 | 常驻 | 按需出现 |
| --- | --- | --- |
| 网格 | 紧凑原生标题条、目录名、可收起文件夹树、缩略图＋单行文件名、精简底栏 | 搜索、排序、密度设置、Inspector、快捷键说明 |
| 大图 | 图片画布；普通窗口保留可靠的系统操作方式 | 左下导航入口、中下翻图/序号、右下缩放、缩略图条、图片信息 |

缩略图仍需提供裁剪预览与完整适应两种显示偏好；现有 `object-fit: cover` 会裁掉部分竖图内容，适合快速扫图，但不能用于判断照片完整构图。默认采用哪一种可在下一次原型对比中验证，无须为此再引入整套布局方案。

## 修改后验收重点

- 同尺寸窗口对比：减少文字后图片可见面积增加，不能靠缩小图片换取更多数量。
- 侧栏隐藏、搜索生效、空结果时，目录和筛选状态依然清楚。
- 鼠标、纯键盘、VoiceOver 均有返回和唤回工具的路径。
- 长文件名、竖图、窄窗口、两种主题不遮挡主要操作；悬浮控件避免覆盖重要画面。
- Space 进入、左右翻图、Esc 返回的选择与滚动位置契约保持不变。
- 原生窗口拖动、全屏、真实像素缩放需在 macOS 实机单独验收。
